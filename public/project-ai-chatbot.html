Project 01

AI Chatbot.

A full-stack AI application built independently, combining a responsive frontend, Flask backend, MongoDB and LLM API integration.

Stack
PythonFlaskMongoDBHTML5CSS3JavaScriptRender

What I built

Designed, developed and deployed the application as a solo project. The backend exposes a REST-style flow, MongoDB stores conversation data and user sessions, and the frontend supports real-time chat interaction.

The project also integrates an LLM API for intelligent, context-aware responses. The work was completed in about 10 days.
